Connect real trackers

Give your GPS vendor this address and key. They send each position as it arrives. Each truck needs its device ID (IMEI) filled in on the Trucks tab.


      
POST, header  x-ingest-key: <your INGEST_KEY>
{ "device_id": "868123045678901", "lat": 28.545, "lon": 77.273,
  "speed_kmph": 18, "time": "2026-11-10T09:42:10+05:30" }

      
If a vendor can't push, ask for their "last location" API and pull it every minute with a scheduled job that posts to the same address.
